# 📱 Quickshell for Hyprland

---

## ⚡ Быстрая установка (One-line installer)

Скрипт проверяет зависимости, устанавливает фирменные шрифты, разворачивает Quickshell и аккуратно добавляет готовый блок кейбиндов в ваш `~/.config/hypr/hyprland.lua`:

```bash
curl -fsSL https://raw.githubusercontent.com/StopNope/quickshell-hyprland/main/install.sh | bash
```

Либо вручную:

```bash
git clone https://github.com/StopNope/quickshell-hyprland.git ~/.quickshell-repo
cd ~/.quickshell-repo
./install.sh
```

## 🔄 Автообновление

Обновление до самой свежей версии из GitHub в 1 команду:

```bash
quickshell-update
```

*(Или через графический интерфейс: `Super + G` ➔ вкладка «Система» ➔ кнопка «Обновить»).*

## 🧰 Диагностика и логи

Установщик и обновлятор сохраняют вывод в пользовательском каталоге состояния:

- Установщик: `~/.local/state/quickshell/installer.log`
- Обновлятор: `~/.local/state/quickshell/updater.log`

Смотреть лог обновлятора в реальном времени:

```bash
tail -F "${XDG_STATE_HOME:-$HOME/.local/state}/quickshell/updater.log"
```

Для ручного запуска Quickshell с подробными сообщениями:

```bash
qs -vv --log-times 2>&1 | tee "${XDG_STATE_HOME:-$HOME/.local/state}/quickshell/runtime.log"
```

Ошибки пользовательских служб можно смотреть через systemd:

```bash
journalctl --user -b -p warning --no-pager
```

Обновлятор останавливается, если в клонированном Git-репозитории есть незакоммиченные изменения, и использует только fast-forward обновление. Сначала сохраните изменения в коммит или stash, затем повторите команду.

## ✨ Возможности

* **Dynamic Top Bar**:
  * Монолитная панель либо парящие капсулы (Островки).
  * **Объединение модулей** в единые капсулы (например, `[ CPU | RAM | GPU ]` или `[ Часы + Погода ]`) с тонкими разделителями.
  * Тонкая настройка длины, высоты и радиуса скругления капсул и фона прямо из графических настроек.
  * Полнофункциональный D-Bus System Tray с поддержкой выпадающих контекстных меню приложений (Telegram, Discord, Steam и т.д.).
* **Pixel Dock**:
  * Плавный автохайдинг с продуманной физикой и жестами.
  * Закрепление приложений, подсветка запущенных окон, контекстное меню по ПКМ.
* **Bento Desktop Widgets**:
  * Виджеты рабочего стола в стиле Material 3: Часы, Календарь с пилюлей текущего дня, Погода с прогнозом, Мониторинг ресурсов (Vitals), Медиаплеер, Хранилище, Заметки.
  * Визуальный редактор виджетов (`Super + Shift + W`): перемещение, изменение размеров и радиуса скругления.
* **Windows 11 Alt+Tab App Switcher**:
  * Переключение окон по `Alt + Tab` с живыми превью, иконками и фокусом при отпускании Alt.
* **Spotlight Launcher & Буфер обмена**:
  * Поиск приложений в стиле Android 15 (`Super + R` / `Super + Space`).
  * История буфера обмена (`Super + V`) с поддержкой текста и изображений.
* **Инструмент скриншотов**:
  * Интерактивный оверлей (`Super + Shift + S` / `Print`) с возможностью редактирования и сохранения.
* **Бесконечный рабочий стол (VxWM Spatial Canvas)**:
  * Пространственная навигация окнами (`Super + D`), плавное панорамирование стрелками или колесом мыши, масштабирование холста (Zoom In/Out).

## ⌨ Горячие клавиши

| Сочетание | Описание |
| :--- | :--- |
| **`Super + G`** | Центр настроек (Бар, Док, Виджеты, Темы, Система) |
| **`Super + U`** | Шторка быстрых переключателей (SidePanel) |
| **`Super + L`** | Экран блокировки (Lockscreen) |
| **`Super + R`** / **`Super + Space`** | Лаунчер приложений и поиск |
| **`Super + V`** | Менеджер буфера обмена |
| **`Alt + Tab`** | Переключатель окон Windows 11 с превью |
| **`Super + Shift + S`** / **`Print`** | Интерактивный скриншот |
| **`Super + N`** | Меню сетей Wi-Fi |
| **`Super + B`** | Меню Bluetooth |
| **`Super + E`** | Меню проводной сети Ethernet |
| **`Super + D`** | Вкл/выкл бесконечный рабочий стол (VxWM) |
| **`Super + Shift + D`** | Ограничивать окна текущим монитором (Clamp) |
| **`Super + Ctrl + ← / → / ↑ / ↓`** | Панорамирование холста бесконечного стола |
| **`Super + Mouse Wheel`** | Вертикальный скролл бесконечного холста |
| **`Super + Shift + Mouse Wheel`** | Горизонтальный скролл бесконечного холста |
| **`Super + =`** / **`Super + -`** | Zoom In / Zoom Out холста |
| **`Super + 0`** | Сброс масштаба холста |
